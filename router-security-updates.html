Field guide / hardware lifecycle

Is your router still getting security updates?

An “end-of-life” label is a reason to investigate. The answer depends on the exact model, hardware revision and what its manufacturer actually says about firmware and security support.

Updated 23 September 2026 · About 3 minutes to read

01

Find the exact model and hardware revision.

Read the label on the device or its box, then confirm the model in the router's administration interface. A family name alone may be too broad. ASUS asks users to check the hardware version, and TP-Link says EOL can apply to a particular version of a model.

02

Read the vendor's words, not just the EOL label.

Look for a product lifecycle page, a firmware support page and any published security update period. Definitions vary: ASUS's networking EOL list says listed models are no longer updated with firmware, while TP-Link's EOL explanation describes production ending for a model or version. An end-of-sale or discontinued notice alone does not establish when security updates stop.

03

Check the firmware and support page.

Compare the installed firmware with the latest version offered for your exact model and revision. Read the release notes and support policy if available. A firmware download date by itself does not prove that security support is continuing or has ended. If the policy is unclear, ask the vendor for the support status of that exact device.

04

Use a scan to collect evidence, then confirm it.

SunsetScan can help identify a device and compare it with local hardware lifecycle records. A result marked lifecycle_review means the vendor signal needs checking; it is not proof that security updates ended. Review the linked source and the device's firmware before deciding what to do.

What to do with the answer

If the vendor explicitly confirms that security updates have stopped, plan a replacement. If the evidence is incomplete, record the model and revision and contact the vendor. Keep the device on its latest available firmware while you investigate. ASUS recommends replacing its EOL routers to receive the latest security updates; check your own vendor's advice for your device.
