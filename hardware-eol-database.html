Inside the database / comparison

224 vendors. One local database.

SunsetScan turns manufacturer lifecycle notices into local scan findings you can use. Coverage spans 224 vendors, and each lookup runs on your machine after setup.

Checked 23 September 2026 · SunsetScan v2.2.1

01

What the 86,276 records mean

The validated v2.2.1 database contains 86,276 lifecycle records, 81,738 model summaries and 224 represented vendors. It is centered on network equipment and related devices, but the full total also includes software, services, modules and accessories. These are database entries, not a count of unique physical devices or network discoveries.

The full validated database ships with the Debian package. Source installs can download smaller profiles. Once installed and set up, scans use local lifecycle data and make no external API call for EOL lookup; initial installation and cache downloads can require internet access.

02

The hard work is in the meaning

Manufacturer notices, support pages and product tables arrive as different file types and with different names for the same milestone. SunsetScan imports and maps vendor source data into common fields, normalizes models and part numbers, handles duplicates, and validates the published build. The database documentation describe that work.

“End of sale,” “end of life,” “end of support,” and “end of security updates” can describe different events. Where the evidence does not prove security patches have stopped, SunsetScan keeps the status for review. The release validation found zero duplicate record IDs and import keys in the promoted database.

04

Where commercial platforms differ

Enterprise catalogs can be much larger. Flexera Technopedia says it covers more than 5 million hardware and software products across more than 100,000 vendors. That broad proprietary catalog covers far more than network hardware.

Device42's optional Enriched Data service uses cloud-based normalization and requires reachable service endpoints. With SunsetScan, you can scan a local network and check installed lifecycle data locally, without an EOL API round trip or a cloud enrichment service during the scan. Commercial platforms offer broader asset-management workflows.

05

Free to try, with a clear data license

The scanner code is MIT licensed. The hardware lifecycle database is separately CC BY-NC 4.0. Noncommercial users need no paid API or subscription for local scanning. Commercial users should review the database license before using the bundled data.
